# EYT Pension Reform and Informal Employment

Current replication materials for **“Türkiye's EYT Pension Reform and Informal Employment: Evidence from Birth Cohorts”**, by **Muhammet Rıdvan İnce**.

The current version is the [October 2026 cohort-informality release](releases/2026-10-cohort-informality/README.md). It contains the 2021–2025 cohort analysis, the separately estimated 2014–2020 diagnostic, aggregate results and the three English manuscript figures. Start with that release's README for configuration, reproduction and validation.

Restricted TurkStat individual and household microdata are not distributed. Obtain them independently under TurkStat's access and reuse conditions: https://www.tuik.gov.tr/Kurumsal/Mikro_Veri . This repository provides analysis code and aggregate outputs, not an unrestricted copy of the underlying data.

The main design compares men born in 1975–1981 with men born in 1982–1984, with 2022 as reference. Cohort membership proxies for reform exposure; estimates do not identify treatment effects among verified EYT beneficiaries. The current paper focuses on employment formality and employment-status composition.

## Earlier materials

The root `analysis/`, `tables/`, `figures/`, `reports/` and earlier `docs/` files are retained for provenance and relate to earlier manuscript versions. They are not the current manuscript's replication entry point. Their original documentation is preserved in [the archived README](docs/README_pre_october_2026.md).
